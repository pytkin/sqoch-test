## Чистая передача исходников

Чистая копия получена из Git-дерева, без `node_modules`, `.venv`, `.env`,
Agent Platform, агентских навыков и авторских кешей. PATH проверки содержал
только Node/pnpm/uv и системные команды; RTK в нём отсутствовал.

- `pnpm run setup` установил все три дерева зависимостей по lockfiles.
- `pnpm verify` прошёл полностью в этой копии.
- `pnpm dev` поднял Vite на 5173 и Uvicorn на 8000. Настоящий браузер
  открыл форму, получил quote 200 через Vite-прокси, подтвердил заказ с 201
  и показал успешный результат. Ошибок JavaScript страницы нет.
- Ctrl+C остановил оба процесса; оба порта освободились.

Удалены приватный gitlink/`.gitmodules`, ссылка навыка и команды Kit/Advisor.
Действующие требования и замеры времени сведены в канонические документы.
Код приложения, API, зависимости и lockfiles этим cleanup не менялись.
Прежнее дерево из 705 файлов сохранено автором локально с SHA-256;
все 627 удалённых файлов имеют точные архивные копии.

Публичная ветка `codex/public-ready` содержит только один начальный коммит
с итоговым деревом: без submodule, старых отчётов и приватной истории.
Основная ветка сохраняет прежнюю историю и отдельный cleanup-коммит.
Для первой публикации предназначена `codex/public-ready`; публикация основной
ветки передаст также прежние удалённые материалы из её истории.

Проверены состав Git-дерева, отсутствие gitlink и приватных путей, отсутствие
родителей начального коммита. Ограниченный текстовый поиск известных форматов
секретов и локальных авторских путей совпадений не нашёл; это не полный
аудит безопасности и не проверка опубликованного remote.

E2E включают реальные расчёт/редактирование/подтверждение, sold_out,
локальные/серверные ошибки, сеть/таймаут/повреждённый ответ, фокус и Undo,
1/4 участника, длинные значения, 320/360/719/720/768/1440 px, 200%,
reduced motion, forced colors и отсутствие побочных сдвигов. Touch-подсказка
проверяется эмуляцией. Исходники проверок доступны в `e2e/`.

## Существенные решения и независимые ревью

API/контракт ранее проходили независимое ревью: закрыты обязательность
выходных полей OpenAPI и loc ошибки состава. После визуального обновления
исправлены доступные описания, положение восстановления и стабильность формы.
Последующий аудит стандартов исправил запрещённые ARIA-имена, невидимые
маски иконок в forced colors, отдельный font CSS и скачок футера при GET.

Независимое read-only ревью публикационного cleanup сравнило документы с
точным прежним деревом, проверило команды, сохранность брифа/API/дизайна/TDD,
все архивные SHA-256 и метаданные видео. Найденная потеря замеров времени
устранена и повторно проверена; открытых подтверждённых P0–P2 нет.
Запуск чистой копии и публичную историю проверял автор изменения.

Дополнительный прогон 23 октября: Firefox 157 desktop и WebKit 27.2 mobile —
8/8 на API/reflow/клавиатуре. На macOS WebKit тест использует Option+Tab по
нативному поведению Safari; assertions фокуса и Enter сохранены. Это отдельный
ограниченный прогон; default verify использует Chromium.

Исторический Lighthouse 13.5/Chrome 156 на локальной production-сборке:
три последовательных запуска/профиль; mobile Performance 87, desktop 100,
Accessibility/Best Practices/SEO — 100. Mobile CLS-медиана после резерва
загрузки 0,00013 против 0,13612 до него. Значимое ускорение FCP не доказано.
Сжатие, cache TTL, HTTPS и полевые метрики нужно проверять на реальном хостинге.
Это замер до публикационного cleanup, не новая оценка каждого изменения копирайта.

## Предел доказательства

- Нет испытаний с реальными пользователями, физическими телефонами и screen reader.
- Автоматические A11y/браузерные проверки не являются сертификатом WCAG.
- Нет production deployment, нагрузки, безопасности платежей или настоящих
  остатков: эти системы отсутствуют по брифу.
- Starlette/HTTPX TestClient выдаёт известное deprecation-предупреждение;
  тесты работают, предупреждение не подавляется.
- Большинство поведения разрабатывалось test-first; выходная OpenAPI-схема
  и часть последующих регрессий добавлялись после первоначальной реализации.
- Ранние полные журналы и варианты сохранены в локальном архиве автора;
  они не требуются для запуска и не объявляются актуальной публичной приёмкой.
- Репозиторий публичный; серверное развёртывание приложения и отправка HR
  не выполнялись.
