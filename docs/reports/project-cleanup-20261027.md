# Cleanup проекта, 27 октября 2026 года

Цель: упорядочить материалы обеих волн, уточнить локальный запуск и проверить
сохранность согласованного поведения. Пользователь отдельно поручил включить
в коммит все накопленные локальные изменения и отправить их в репозиторий.

## Структура и сохранность

- Действующие требования и технические решения перечислены в
  [карте документации](../README.md); команды запуска принадлежат
  [корневому README](../../README.md).
- Датированные ревью и завершённые этапы собраны в
  [истории](../history/README.md). Исторические PASS и числа тестов относятся
  к своим срезам, а не ко всем последующим изменениям.
- Прежние исследования интерфейса и неиспользуемые runtime-иконки Lucide
  перенесены в [архив дизайна](../design/archive/README.md) вместе с лицензиями.
  Принятые kit, макеты переноса, шрифты, логотип, Phosphor Bold, screenshots
  и оба видео сохранены.
- Перемещены 27 файлов; ссылки обновлены. Перенесённые изображения, SVG,
  лицензии и metadata сохранены побайтово. Исторические тексты менялись только
  для ссылок и явного обозначения границы прежних результатов.
- Исполняемые исходники, зависимости, fixtures, миграции и генерируемый API
  в рамках cleanup не менялись. Ранее накопленные изменения обеих волн
  проверяются и включаются в общий результат по поручению пользователя.
- Рабочая SQLite, письма Mailpit, резервные копии и локальные ключи сохранены.
  Игнорируемые `.cache`, `.local`, `.env`, `data` и служебный Agent Platform
  не являются публикационным набором.

## README и доказательства запуска

README содержит последовательность от чистых исходников: версии инструментов,
frozen/locked-установка, `.env`, Mailpit, схема и демоданные, запуск web/API/worker,
проверка готовности, сценарий переноса, остановка, продолжение и явный сброс.
Отдельно описаны ручной режим без ключа, согласование портов, фиксированный
год fixtures и локальный просмотр сборки.

Повторный `pnpm verify` завершён успешно: **897 passed** (346 frontend,
432 backend, 45 tooling, 74 desktop/mobile E2E). Также прошли typecheck,
lint, форматирование, `contracts:check`, build и проверка локальных ссылок
в 37 Markdown. Сохранилось известное предупреждение Starlette/HTTPX,
описанное в приёмке. Исполняемые исходники, тесты, fixtures и инструменты
сверены с состоянием до cleanup: **135 файлов без изменения SHA-256**.

В изолированном наборе неигнорируемых исходников без Agent Platform и ключа
DeepSeek выполнены `pnpm run setup`, `db:init`, `demo:load` и `pnpm dev`.
Все три frozen/locked-установки успешны, lockfiles не изменились; Vite,
Uvicorn и worker сообщили о готовности. Изолированный Mailpit запущен
отдельным Compose project на портах 11026/18026. Семнадцать HTTP-проверок
web, API и assets завершились с 200; ответы API напрямую и через Vite
совпали. После чтений SQLite сохранила 2 мероприятия, 20 покупок,
0 подготовок и 0 заданий отправки.
Повторные `db:init` и запуск сохранили содержимое всех четырёх таблиц;
ещё четыре HTTP-проверки прошли после restart. Проверочный Compose остановлен
без удаления volume. Рабочие API/web/worker возвращены к прежней SQLite
с одним подтверждённым переносом и восемью отправлениями; восемь писем
основного Mailpit сохранены.

Независимое read-only ревью не выявило P0–P2 в cleanup, документации
и проверенном публикационном наборе. Исправлены два GitHub anchor в ссылках
на приёмку SQOCH-39–44. Для трёх новых документов исходный текст до
актуализации не сохранился у независимого рецензента; проверены текущие
правила и их согласованность. Повторный запуск здесь проверяет ручной режим
без ключа; новый вызов DeepSeek и SMTP-отправка в этот cleanup не входили.
Предыдущая браузерная приёмка, живые интеграции, 42/42 предметные мутации
и видеозапись сохранены в [отдельном отчёте](event-transfer-browser-20261027.md).
