# UI kit Sqoch: пересмотр 27 октября 2026

Последний показанный набор: три редакции минерального основания,
Golos Text и Phosphor Bold. Номера относятся к последним трём изображениям:

| Порядок показа | Макет                               | Наблюдаемая композиция                                             |
| -------------- | ----------------------------------- | ------------------------------------------------------------------ |
| 1              | [Редакция 1](mineral-variant-1.png) | Собранная рабочая плотность, образцы слева и форма справа          |
| 2              | [Редакция 2](mineral-variant-2.png) | Другая расстановка компонентов, близкая плотность к первой         |
| 3              | [Редакция 3](mineral-variant-3.png) | Более свободная правая колонка образцов, вертикальные поля в форме |

Второй запрос предполагал более воздушный результат, но генерация сохранила
близкую к исходной плотность. Для третьей редакции компоновка изменена явно:
меньше демонстрационных блоков и больше свободного пространства между ними.
Пользователь выбрал третий вариант. Его вертикальная форма и свободные
интервалы становятся основанием SQOCH-33 для обеих волн приложения.

[Полные запросы](prompts.md), [реестр изображений](mineral-variants.json).
Логотип, гарнитура, минеральная палитра и вес иконок общие; точность метрик
проверяется по реальному [образцу кнопок](button-proof.html).

Цель: заменить отклонённую визуальную систему обеих волн, сохранив логотип,
информативность текстов и [инварианты сценариев](../interaction-invariants.md).
Основание: [эвристический аудит](../../history/design/design-reset-audit-20261027.md).

## Реальные исходники и измерения

- [Исходный логотип](assets/sqoch-wordmark-source.png) снят из текущего приложения.
  CSS оригинала: Commissioner 40/48 px, вес 700, letter-spacing -1 px,
  цвет #536B83. Он сохраняется отдельно от нового UI-шрифта.
- [HTML сравнения гарнитур](font-proof.html) и
  [снимок браузера](../../preview/design-reset-20261027/07-real-fonts.png).
  Все три файла реально загружены; выбранным пользователем ориентиром стал Golos Text.
- [Образец кнопок](button-proof.html) использует настоящий локальный Golos Text
  и [Phosphor Bold SVG](icons/phosphor-bold/sources.json). Лицензия MIT сохранена.
- В браузере проверены высота кнопки 48 px, глиф 18×18 px, gap 6 px,
  padding 11×18 px, текст 16/24 px, вес 500 и трекинг +0.01em (0.16 px).
  В ходе проверки явно исправлено наследование letter-spacing у native button.
- [Regular](button-proof-regular.html) сохранён как отклонённый по толщине образец;
  он не подменяет новый Bold. Старый [снимок](../../preview/design-reset-20261027/08-phosphor-buttons.png)
  относится к проверке Regular. Актуальный [снимок Bold](../../preview/design-reset-20261027/09-phosphor-bold-buttons.png)
  подтверждает загрузку правильных SVG и сохранение размеров/интервалов.
- [Font source manifest](fonts/sources.json) содержит URL, SHA-256 и лицензии.
  [Иконографический источник](https://github.com/phosphor-icons/core) является
  официальным владельцем SVG. В SQOCH-33 эти ассеты скопированы в public
  и используются обеими волнами приложения.
- [Палитры и расчёт контраста](palettes.json). Для выбранного минерального
  основания текст/surface 13.05:1, muted/canvas 5.54:1, white/primary 6.92:1.
  Это расчёт заданных hex-токенов, а не пикселей растра.

## Границы результата

Image Gen выдаёт направления. Он не подтверждает реальный CSS, точную
гарнитуру, контраст и хит-зоны. Размеры первых трёх PNG 1448×1086 при
запрошенном ориентире 1920×1440; они сохранены без масштабирования.
Оригиналы и SHA-256 находятся в [реестре](initial-kits.json).

Известные отклонения первого набора: мелкие подписи на доске компонентов,
поля/иконки могут отличаться от указанных размеров; во втором kit один пример
заполненного имени ошибочно сопровождается сообщением о пустом поле;
в третьем одна неизвестность окрашена как ошибка. Эти случаи не являются
правилами реализации и не заменяют семантические состояния/реальные образцы.

В SQOCH-32 исправлена пунктуация статических текстов без длинного тире.
В SQOCH-33 третий вариант перенесён в рабочие потоки обеих волн: локальный
Golos Text, Phosphor Bold, новая сетка, поверхности и состояния.
Сравнения, исправленные регрессии и предел доказательства: [design QA](../../history/design/design-qa-sqoch-33-20261027.md).
Итоговый pnpm verify exit 0: 123 frontend, 291 backend, 28 tooling и66 E2E,
всего508. Типы/lint/формат/контракт/build/docs green. Skill validator пройден;
независимое read-only ревью не выявило новых P0–P2 в документах/пунктуации.
Начальная ошибка окружения E2E из-за занятого порта устранена освобождением
собственного preview; после проверки он восстановлен с прежней QA-базой.
