# Design QA: выбранный третий kit

Дата: 27.10.2026. Срез SQOCH-33, обе волны Sqoch.

final result: passed

## Источник и нормализация

Визуальная истина: [третий показанный вариант](../../design/ui-kits-20261027/mineral-variant-3.png),
1374×1145 px. Это UI kit с примером формы и образцами компонентов,
а не готовая спецификация всех экранов. Принятые точные метрики принадлежат
[дизайн-системе](../../design-system.md) и реальному HTML specimen.

Локальный результат: http://127.0.0.1:5173/ и #/organizer. Сопоставимое состояние:
пустое имя с ошибкой, возраст 28, email anna@example.com. Runtime viewport
1374×1145 CSS px, DPR 1; [PNG](../../preview/ui-kit-3-20261027/11-booking-reference-state.png)
1374×1262 px содержит всю страницу. Для общего сравнения взяты верхние
1374×1145 px. Никакого масштабирования шрифта не применялось.

Открыты вместе [полное сравнение](../../preview/ui-kit-3-20261027/12-comparison-full.png)
и [сравнение формы](../../preview/ui-kit-3-20261027/13-comparison-form.png).
У формы источника crop x89/y278, 731×855 px, у runtime x321/y112,
732×1054 px. Высоты намеренно не растянуты до совпадения.

В приложении сохраняются подробные правила покупки, подсказка возраста,
динамический тариф и резерв его высоты. Поэтому рабочая форма выше примера
в kit; в ней нет демонстрационных цветовых/компонентных панелей. Единственный
исходный логотип и шаг находятся в заголовке страницы. Мелкие растровые
подписи Image Gen не переносятся ниже принятого минимума 16 px.

## Итерации и исправления

1. Первая реализация: рабочая поверхность 800 px была шире примера 731 px.
   P2 по пропорциям. Исправлена до 732 px, ширина внешней страницы 780 px
   с двумя отступами по 24 px. Повторное сравнение: 11–13, размеры выше.
2. Регрессия ссылок: Tailwind reset снял подчёркивание Mailpit. P2 по
   различимости действия. Явное underline возвращено всем текстовым ссылкам;
   логотип имеет отдельное text-decoration: none. Существующий E2E красный
   до исправления, green после него на desktop и mobile.
3. В первом mobile result при 360×800 нижняя граница кнопки сверки была
   на 876 px. P2 по доступности восстановления. Убрана вложенная поверхность
   прогресса; для кабинета адаптированы интервалы и заголовок. Кнопки,
   текст и hit area не уменьшены. Старый тест первого экрана сохранён.
   [Итоговый реальный результат](../../preview/ui-kit-3-20261027/14-organizer-progress-mobile-top.png)
   является crop верхних 360×900 px full-page PNG при viewport 360×800.
   Кнопка заканчивается до 800 px; E2E с двумя действиями также подтверждает
   исправление.
4. На mobile заметен отрыв «в» от продолжения правила сопровождения.
   Исправлены точечные связи числа с «лет», «от» и «в том» через NBSP.
   Значения и смысл текста сохранены, unit и responsive проверки green.

## Границы и завершение

Нет открытых подтверждённых P0–P2 в дельте выбранного визуального среза.
Это не закрывает автоматически все исторические находки аудита и не
является исследованием с пользователями или сертификатом WCAG. Native
browser zoom, физические устройства и screen reader отдельно не проверялись;
200% проверены существующим эквивалентным CSS viewport/DPR E2E.
Сценарии LLM/SMTP в автоматических проверках используют изолированные
контролируемые ответы, не доказывают внешнюю доставку. Интерфейс и API
предпросмотра подключены к прежней локальной QA-базе.

Ревью выполнено новым независимым агентом: весь baseline-diff и CSS,
семантика, каскад organizer, реальные screenshots и manifest; 82 frontend
проверки повторены независимо. Подтверждённых P0–P2 не найдено.

Checklist: выбранный kit зафиксирован; font/assets загружены; состояния
и переносы проверены; сравнения открыты; регрессии исправлены; локальный
предпросмотр сохранён. Видео и публикация не выполнялись.
