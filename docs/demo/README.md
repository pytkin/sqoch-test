## Демонстрация переноса мероприятия от 27.10.2026

Эта запись сделана после исправлений по отдельному запросу пользователя.
Историческое видео checkout выше сохранено без замены.
Новый ролик показывает текущий минеральный kit и полный путь организатора:

1. Обзор мероприятий и открытие «Керамики» с текущими датой и временем.
2. Запрос помощнику о переносе без явного года и ожидание настоящей DeepSeek.
3. Автоматически подготовленные мероприятие, новая дата, тема и письмо.
4. Человеческая проверка текста и отдельный серверный preview с восемью email.
5. Отдельное подтверждение смены даты и уведомления покупателей.
6. Результат 8/8, письмо в локальном Mailpit и история мероприятия.

| --------------- | -------------------------------------------------------- |

| 12–25 с         | Ожидание ответа AI и готовый перенос с текущим годом     |
| 25–39 с         | Редактирование и сохранение письма, человеческая отметка |
| 39–47 с         | Серверный preview с восемью получателями                 |
| 47–69 с         | Отдельное подтверждение, 8/8 и результаты получателей    |
| 69–76 с         | Список писем и текст уведомления в Mailpit               |
| 76–88 с         | Новая дата и история мероприятия                         |

Перед записью тестовая БД и Mailpit очищены после согласованного backup.
«Керамика» перенесена с 10 ноября 2026 года, 19:00 на 20 ноября 2026 года,
19:00 по Москве. «Живопись» осталась на прежней дате. Восемь принятых писем
сверены по To, теме, полному substantive plain-text body и единственному
Message-ID, у каждой доставки одна попытка. Внешним адресатам письма не доставлялись.

по mtime файлов. Скорость ролика не подтверждает длительность ответа LLM.
