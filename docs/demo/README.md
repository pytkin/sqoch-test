# Демонстрация оформления

[Смотреть MP4](checkout.mp4) · [Кадр результата](checkout-poster.jpg)

Перезаписано 23 октября 2026 года после уточнения текстов и обратной связи
оформления (`9258e03`), с настоящим локальным FastAPI и production-сборкой
frontend. Видео: 57,633 с, 1440×1050,
H.264, yuv420p, 30 fps, без звука. Это итоговая демонстрация продукта,
а не запись разработки. Имена тестовые, email — anna@example.com.

| Примерное время | Сцена                                                       |
| --------------- | ----------------------------------------------------------- |
| 0–9 с           | Начальная форма и развёрнутые правила покупки               |
| 9–19 с          | Ребёнок 13 лет; ошибка объясняет добавление сопровождающего |
| 19–30 с         | Добавление сопровождающего; серверный расчёт 3 000 ₽        |
| 30–38 с         | Изменение возраста на 14; повторный расчёт 4 000 ₽          |
| 38–48 с         | «Нет мест»: причина отказа, данные и инструкция повтора     |
| 48–51 с         | Выбран «Успех», ошибка остаётся до ручного подтверждения    |
| 51–58 с         | Успешное подтверждение и текущая серверная сумма            |

Действия выполнены через agent-browser 0.39.2 в изолированной сессии;
наложен только указатель мыши. Контрольные ответы и сумма проверены во время
записи. Сообщение отказа и кнопка помещаются в кадре; на чтение предусмотрена
пауза около 9 секунд. Выбор radio сам не создаёт заказ. Ключевые кадры
из MP4 и обзор 18 сцен осмотрены. Состояния приложения не подменялись; приложение не сохраняет
настоящих заказов и не отправляет писем. MP4 подготовлен с faststart для
удобного просмотра. Автозапись и FFmpeg не являются зависимостями проекта.
