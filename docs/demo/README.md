# Демонстрация оформления

[Смотреть MP4](checkout.mp4) · [Кадр результата](checkout-poster.jpg)

Записано 23 октября 2026 года на текущем интерфейсе, с настоящим локальным
FastAPI и production-сборкой frontend. Видео: 43,6 с, 1440×1050,
H.264, yuv420p, 30 fps, без звука. Это итоговая демонстрация продукта,
а не запись разработки. Имена тестовые, email — anna@example.com.

| Примерное время | Сцена                                                       |
| --------------- | ----------------------------------------------------------- |
| 0–7 с           | Начальная форма и правила покупки                           |
| 7–15 с          | Ребёнок 13 лет; проверка требует сопровождающего от 18 лет  |
| 15–24 с         | Добавление сопровождающего; серверный расчёт 3 000 ₽        |
| 24–32 с         | Изменение возраста на 14; повторный расчёт 4 000 ₽          |
| 32–38 с         | Демосценарий «Нет мест», сохранённые данные и ручной повтор |
| 38–44 с         | Успешное подтверждение и текущая серверная сумма            |

Действия выполнены через agent-browser 0.39.2 в изолированной сессии;
наложен только указатель мыши. Контрольные ответы и сумма проверены во время
записи. Состояния приложения не подменялись; приложение не сохраняет
настоящих заказов и не отправляет писем. MP4 подготовлен с faststart для
удобного просмотра. Автозапись и FFmpeg не являются зависимостями проекта.

Видео предназначено для передачи пользователем; внешняя отправка не выполнялась.
